Ch1: BASICS & PROOFS
Amdahl's Law
If W has serial part Ws:
S ≤ W / Ws
Proof: Tp ≥ Ws (serial part can't parallelize)
S = W/Tp ≤ W/Ws
Core Definitions
SpeedupS = Ts / Tp = W / Tp
EfficiencyE = S / p
CostC = p · Tp
OverheadTo = p·Tp - W
E range: 0 < E ≤ 1
Cost Optimal
p · Tp = O(W)
Parallel cost = sequential work
Equivalently: E = Θ(1)
Isoefficiency
W = K · To
How W must grow with p to maintain E
Lower isoeff = better scalability
To vs Tp Relationship
If To ≤ Θ(p):
→ Tp keeps decreasing, approaches constant
If To > Θ(p):
→ Tp has a MINIMUM (first ↓ then ↑)
Find min: dTp/dp = 0
Task Graph Analysis
Max concurrencyMax parallel tasks
Critical pathLongest dependency chain
Max speedupTotal work / Critical path
Min procs= Max concurrency

Dijkstra Token Termination
TopoRing
TokenWHITE or BLACK
ProcessorWHITE or BLACK
Rules:
• All start WHITE
• Proc→BLACK if send to LOWER ID
• Token→BLACK if pass BLACK proc
• BLACK proc passes token, turns WHITE
DONE: WHITE token arrives at WHITE P0
Tree-Based (Weights)
StartP0 weight=1
Give workSplit weight ½
FinishReturn weight to giver
DONEP0 weight=1 again
Drawback: Weights get tiny (precision)
Fix: Use fractions or integers
