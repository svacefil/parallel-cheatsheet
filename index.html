Amdahl's Law Proof
If W has serial part Wₛ:
S ≤ W / Wₛ
Proof:
  Tₚ ≥ Wₛ  (serial part cannot be parallelized)
  S = W/Tₚ ≤ W/Wₛ

No matter how many processors, speedup bounded by W/Wₛ.
Core Definitions
SpeedupS = Tₛ / Tₚ = W / Tₚ
EfficiencyE = S / p = W / (p·Tₚ)
CostC = p · Tₚ
OverheadTₒ = p·Tₚ - W
E range: 0 < E ≤ 1 (1 = perfect parallelization)
Cost Optimal
p · Tₚ = O(W) ⟺ E = Θ(1)
Parallel cost equals sequential work (up to constant factor)
Tₒ vs Tₚ Relationship Proof
Tₚ = W/p + Tₒ/p

Case 1: Tₒ ≤ Θ(p)
  Tₒ/p ≤ c (constant)
  As p→∞: W/p→0, Tₒ/p→constant
  → Tₚ approaches constant, keeps decreasing

Case 2: Tₒ > Θ(p), say Tₒ = Θ(p^α), α>1
  Tₚ = W/p + Θ(p^{α-1})
  dTₚ/dp = -W/p² + (α-1)Θ(p^{α-2}) = 0

  At small p: -W/p² dominates → Tₚ decreasing
  At large p: +Θ(p^{α-2}) dominates → Tₚ increasing
  → Tₚ has distinct MINIMUM

One processor (the root) has p−1 different messages, each of size m. It needs to send one message to each of the other processors.

Processors are connected in a straight line. The root can only send data through ONE link.
Root ——— P1 ——— P2 ——— P3 ——— P4 ——— P5 ——— P6 ——— P7 ^ | Only ONE link leaves the root

Everything must squeeze through that single link.
Root must send(p−1) messages
Each message hasm words

Time = tᵥ × [total words leaving root] = tᵥ × m × (p−1)
Why is This Optimal?
Physical limit: You cannot send m×(p−1) words through a link faster than tᵥ per word.
The algorithm achieves exactly this limit.
Therefore, no other algorithm can do better. This is the best possible time.

2D Transpose Algorithm (p < n) [12 pts]
Q: Derive Tₚ, S, E for 2D transpose FFT on linear array of p nodes (p<n). Describe meaning of each term.
Idea: Treat n-point FFT as √n × √n matrix. Each proc holds n/p elements.
Algorithm Steps
1. Local FFT on n/p elements (column-wise)
2. Transpose (all-to-all personalized) — redistribute data
3. Local FFT on n/p elements (row-wise)
4. Transpose again
Parallel Runtime (LINEAR ARRAY)
Key: On linear array, all-to-all personalized has Θ(p) startups, NOT log p!
All-to-all personalized on ring/linear array:
  T = (p-1)tₛ + (p-1)(n/p)·p/2·tᵥ  [neighbor exchange model]
  ≈ (p-1)tₛ + n(p-1)/2·tᵥ

Simplified: Tcomm_transpose ≈ p·tₛ + (np/2)·tᵥ per transpose

Tₚ = Tcomp + Tcomm
Tcomp = (n/p)·log n        [local FFTs]
Tcomm = 2·[(p-1)tₛ + (n/p)·(p-1)·tᵥ]  [2 transposes]
Tₚ = (n/p)log n + 2(p-1)tₛ + 2(n/p)(p-1)tᵥ
Meaning of each term
• (n/p)log n = local FFT work (n/p points, log n stages)
• 2(p-1)tₛ = startup for 2 transposes (p-1 comm steps each on linear array)
• 2(n/p)(p-1)tᵥ = data transfer for transposes
Speedup and Efficiency
W = n log n
S = W/Tₚ = (n log n) / [(n/p)log n + 2(p-1)tₛ + 2(n/p)(p-1)tᵥ]

For large p:
S ≈ (n log n) / [(n/p)log n + 2p·tₛ + 2n·tᵥ]
E = S/p

Isoefficiency: Tₒ = 2p²tₛ + 2pn·tᵥ → W = Θ(p²) (dominated by startup)
Contrast with hypercube: On hypercube, transpose uses log p phases → much better scalability.
Assumption: Linear array uses neighbor-exchange routing for all-to-all personalized (p-1 phases). If tree/hypercube embedding assumed, use Θ(log p) phases instead.

Find Minimum Tₚ (tₛ=0) [14 pts]
Q: Given Tₚ=(n/p)logn + tᵥ(n/p)logp, max p=n. Find p when Tₚ is minimal and find Tₚᵐⁱⁿ for tᵥ=10.
Given: Tₚ = (n/p)log n + tᵥ(n/p)log p, constraint: 1 ≤ p ≤ n
Step 1: Check derivative
Tₚ = (n/p)[log n + tᵥ log p]

dTₚ/dp = d/dp[(n/p)(log n + tᵥ log p)]
       = (-n/p²)(log n + tᵥ log p) + (n/p)(tᵥ/p·ln2)
       = (n/p²)[-log n - tᵥ log p + tᵥ/ln2]

Setting = 0: log n + tᵥ log p = tᵥ/ln2 ≈ 1.44tᵥ

For tᵥ=10: log n + 10 log p = 14.4
Step 2: Check second derivative (is it min or max?)
d²Tₚ/dp² evaluated at stationary point...
Result: POSITIVE → stationary point is a MAXIMUM, not minimum!

This means: minimum occurs at BOUNDARY of [1, n]
Step 3: Compare endpoints
At p=1:
  Tₚ(1) = n·log n + tᵥ·n·0 = n log n

At p=n:
  Tₚ(n) = (n/n)log n + tᵥ(n/n)log n
        = log n + tᵥ log n = (1 + tᵥ) log n

For tᵥ=10:
  Tₚ(1) = n log n
  Tₚ(n) = 11 log n

Which is smaller? For n > 11: Tₚ(n) < Tₚ(1)
Tₚᵐⁱⁿ = (1 + tᵥ) log n = 11 log n at p = n
Key insight: Stationary point from dTₚ/dp=0 is a MAXIMUM. Min is at endpoint p=n for typical n.
